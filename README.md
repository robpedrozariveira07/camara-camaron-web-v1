# Cámara Camarón · Web one-page (versión 1: carrusel)

Sitio de una sola página para Cámara Camarón, Cocina del Mar (Victor Hugo 88, Col. Portales, CDMX).

## Estructura
- `index.html`: el sitio completo (HTML + CSS + JS en un solo archivo)
- `img/`: logo, favicon y fotos optimizadas

## Configuración
Al final de `index.html`, en el bloque `CONFIG`:
- `messenger`: enlace de Messenger de la página (los botones agregan `?ref=web_...` para medir de dónde viene cada mensaje)
- `whatsapp`: número con formato `52` + 10 dígitos. Si se llena, los botones cambian a WhatsApp y aparece el ícono.
